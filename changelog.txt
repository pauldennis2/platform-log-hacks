# Changelog

## 0.4.2
- Fix: Platform Request Driver tint now reduces red and boosts blue to give a silver-white appearance on the red-based constant combinator sprite
- Change: Platform Pilot reads space-location signals from both wires (red and green), sorted by value ascending; if the same planet appears on both wires, the lower value is used

## 0.4.1
- Fix: Platform Request Driver now visually distinct from vanilla constant combinator (silver-grey tint applied to all sprite layers)
- Change: Platform Pilot now reads all space-location signals from red wire only, sorted by value ascending; supports arbitrary multi-stop routes (e.g. Fulgora=1, Nauvis=2, Aquilo=3)

## 0.4.0
- Breaking: existing "Platform Request Driver" (power switch) renamed to "Platform Pilot" — handles routing only
- Add: new "Platform Request Driver" (constant combinator, silver-white tint) — handles hub logistic requests; stack multiple for different source planets
- Change: hub requests and platform routing are now independent devices under the plh-platform-logistics technology

## 0.3.6
- Add: PRD station wait time is now configurable in mod settings (default 30s, range 5–600s)

## 0.3.5
- Add: Platform Request Driver now has its own technology (plh-platform-logistics), requiring 200 each red/green/blue/white science and prerequisites space-platform + plh-speciality-combinators
- Balance: PRD recipe updated to 20 processing units, 5 advanced circuits, 5 steel

## 0.3.4
- Fix: Platform Request Driver now also inserts destination planet (green wire) as a temporary schedule stop after the source stop
- Fix: PRD schedule cleanup now correctly removes both source and destination stops on deactivation or removal
- Fix: PRD no longer adds schedule entries while switched off or after removal

## 0.3.3
- Fix: Quality Reader and Quality Modulator "Read Quality" mode now count all signal types by quality tier, not just items
- Add: Quality Modulator "Read Quality" mode

## 0.3.2
- Remove: Mini Signal Receiver — use compaktcircuit iconnectors for cross-surface circuit bridging instead
- Remove: aai-signal-transmission hard dependency (no longer required)

## 0.3.1
- Fix: Quality Reader now outputs quality-type signals correctly (explicit quality="normal" field required)
- Add: Quality Modulator "Set Quality" mode — outputs all input signals at a fixed quality tier
- Fix: Quality Modulator and Quality Multiplexer now handle all signal types (space-location, fluid, etc.), not just items
- Fix: Blueprint and copy-paste settings now preserved for all custom combinators
- Fix: Stale change-detection cache no longer persists across mod updates (on_configuration_changed clears entity_keys)

## 0.3.0
- Fix: Recipe Reader no longer outputs recycler for basic items (recycling crafting category excluded)
- Fix: Recipe Reader output count now reflects item quantity rather than always 1 per item type
- Fix: Signal Type Detector now outputs virtual signals correctly (quality field required in Factorio 2.0 section filters)
- Fix: Non-recoverable crash on game load when entity_keys storage table was absent
- Perf: Change detection across all update functions — section.filters write skipped when input is unchanged
- Perf: Update tick rate reduced from every 2 to every 6 ticks
- Perf: Signal Type Detector categorize() now caches prototype lookups

## 0.2.0
- Fix: rescan all surfaces on_configuration_changed to register entities whose output companion was silently lost (fixes Quality Reader, Storage Reader, Recipe Reader, Quality Gate not outputting)
- Perf: add engine-level entity name filters to built/mined event handlers (eliminates callbacks for all non-PLH entities)
- Perf: move companion combinator initialization (enabled, section.active) from every-tick path to placement time

## 0.1.9
- Quality Modulator and Quality Gate: add X close button, draggable titlebar, fix Escape not closing the GUI

## 0.1.8
- Storage Reader: remove custom virtual signal, output signal-A = % available space (100 - % full)

## 0.1.7
- Add Quality Reader: strips item identity from signals, outputs quality signals summed across all input items

## 0.1.6
- Quality Gate: add "Signal" mode — passes items whose quality matches any quality signal present on the input

## 0.1.5
- Quality Gate: add mode dropdown — "Allow only" (existing behavior) or "Allow all but" (inverted)

## 0.1.4
- Add Quality Multiplexer: sums each input item across all qualities, outputs that total at every quality tier

## 0.1.3
- Add Storage Reader: outputs plh-sig-fullness (0-100) for directly-wired chests or fluid tanks; averages across multiple connected storages

## 0.1.2
- Add Recipe Reader: outputs a building signal for each input item (the machine that produces it); count = number of distinct input items using that machine type

## 0.1.1
- Add Quality Gate: passes only item signals matching the selected quality tier

## 0.1.0
- Quality Modulator: add Steps dropdown (1-4) for upstep mode; quality wraps circularly (legendary+1 = normal)
- Quality Upstepper and Modulator upstep now share the same wrapping modular-arithmetic quality logic

## 0.0.8
- Add Quality Modulator: single entity with Upstep/Remove mode selectable via dropdown GUI

## 0.0.7
- Add Quality Up-stepper: bumps all input item signals up one quality tier
- Add Quality Remover: strips quality from all input item signals
- Add Signal Type Detector: categorises input items by group, outputs one virtual signal per category
- Platform Request Driver now adds a temporary schedule stop to navigate to the source planet
- Platform Request Driver is now restricted to space platforms (returns item to player if placed elsewhere)
- Fix: use Factorio 2.0 wire connector API (`get_wire_connector` / `connect_to`)

## 0.0.1
- Initial release: Platform Request Driver, Mini Signal Receiver
